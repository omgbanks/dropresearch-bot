# DropResearch Telegram Bot

## Deploy FREE on Railway (2 minutes)

1. Go to **railway.app** → sign up free with GitHub
2. Click **"New Project"** → **"Deploy from GitHub repo"**
3. Upload these files to a GitHub repo first, then connect
4. Railway auto-detects Python and deploys

## OR — Deploy on Render (also free)

1. Go to **render.com** → sign up free
2. New → **Background Worker**
3. Connect GitHub repo
4. Build command: `pip install -r requirements.txt`
5. Start command: `python bot.py`
6. Deploy — done!

## Bot Commands
- `/research [keyword]` — Score 5 products
- `/winner [product]` — Full winner analysis + variants
- `/hooks [product]` — 5 viral pity hooks
- `/script [product]` — Full video script
